BADEMALIK & BACCHA — HER LITTLE WORLD

A responsive 3D keepsake book dedicated to her personality, playful expressions,
childish side, laughter and little moments.

CONTENTS
- index.html: website structure
- style.css: desktop, tablet and mobile styling
- app.js: 12 page stories, secret notes, Polaroid captions and quotes
- assets/photos/: 12 bundled memory photos (memory-01.jpg to memory-12.jpg)

RUN LOCALLY
Open index.html in a browser. For best results, use VS Code Live Server.

DEPLOY TO GITHUB + VERCEL
1. Extract this ZIP.
2. Upload the complete bestie-book folder contents to a GitHub repository.
3. Import that repository into Vercel.
4. Use the project root as the deployment root; no build command is required.
5. Deploy. Keep assets/photos alongside index.html, style.css and app.js.

The included photos are part of the website and appear for every visitor. Any optional
photo replacements made through the editor are stored only in that visitor's browser.
The book adapts to laptop, tablet and mobile screens. On narrow screens, each page
shows its matching photo above the text so the memory remains visible.
